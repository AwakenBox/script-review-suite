# V2：故事质量

规则版本：0.1.0。6 项，各 20 分；先判断 0—10 整数 `score_10`，呈现分数为其两倍，完整评分满分 120。

## 定位与材料

回答：不考虑剧本格式，材料已经呈现的故事是否成立、持续吸引人，并带来情感或意义上的回报？

可使用剧本、小说、故事大纲或口述整理。完整评分需要足以判断故事主要发展、人物选择和结尾的材料，不强制要求逐场景剧本；一句梗概的吸引力不能证明完整故事成立。只评已呈现内容，不能用评审自行补写的连接和结尾加分。

下表内部 6/10、8/10 分别呈现为 12/20、16/20；允许使用其间整数 `score_10`。材料不足标暂不可评，不用中间分代替。缺项与总分按主文件统一规则执行。

## 分项锚点

| ID | 维度 | 内部 6/10 → 12/20 | 内部 8/10 → 16/20 |
|---|---|---|---|
| V2-01 | 故事前提吸引力 | 核心情境、问题或关系值得展开，但区别于常见故事的具体特征较弱 | 前提具体且有辨识度，包含值得追随的问题或关系，能说明为何这个故事值得展开 |
| V2-02 | 人物与关系成立度 | 人物及主要关系基本可信，但某些选择工具化，或关系层次不足 | 人物欲望、矛盾和选择具体可信，互动塑造有层次的关系，能持续牵动关注 |
| V2-03 | 故事发展逻辑 | 主要发展自洽，但关键条件、选择后果或事件连接有未补足之处 | 事件及其后果符合已建立的世界与人物，关键发展可追溯，惊喜不破坏可信度 |
| V2-04 | 结构与信息组织 | 叙述顺序和结尾基本有效，但重要铺垫、揭示或回应位置欠佳 | 顺序、铺垫、揭示和收束共同组织有效体验，所需信息在适当时机产生作用 |
| V2-05 | 持续吸引力 | 有明确观看或阅读动力，但中段出现无新期待的重复或停滞 | 冲突、悬念、好奇、幽默或情感牵引持续有效，各段为继续阅读提供具体理由 |
| V2-06 | 情感与意义回报 | 故事带来可辨认的感受或认识，但最终回报弱于此前建立的期待 | 情感、认知或体验上的回报由此前发展充分积累，结尾使主要期待得到有力回应 |

## 容易误判的边界

- 前提吸引力判断开始追随的理由；持续吸引力判断整个发展过程；回报判断发展最终带来的体验。不能仅凭一个好创意给三项高分。
- 人物项判断人物与关系的可信度和丰富程度；逻辑项判断事件条件、连接和后果。人物工具化若还破坏了情节可信度，需分别列证据与后果。
- 不因非剧本格式、缺镜头描述、无对白或语言朴素扣分。文笔仅在妨碍理解故事事实时影响相应判断。
- 不要求冲突激烈、反转频繁、主角变好或明显改变。坚持、被逐渐理解和关系变化均可成立。
- 慢叙事、片段结构、循环结构和开放结尾不自动扣分；检查所选形式是否维持关注，是否回应已建立的主要期待。
- “没有交代所有谜底”不等于没有回报；“写明结局”也不等于已经完成情感积累。
- 高概念新颖度不能替代人物与因果证据；作品涉及重大题材也不自动增加意义回报分。
