# K01 人物行动：先找选择的根据

ID：K01。关联维度：V1-02、V1-04、V1-05、V2-02、V2-03。

**来源概括**：Academy Nicholl 的公开评审问题关注：主要人物是否以行动推动故事，行动是否符合已建立的人物，还是仅仅方便情节发生。它同时询问人物是否让读者关心其遭遇。

**判断用法（本产品推论）**：遇到“突然原谅”“突然背叛”，沿原稿寻找三件事：此前想得到或避免什么，当场新增了什么压力或信息，做出选择会失去什么。先指出缺失的连接，再建议补一个有作用的行动或条件，不默认增加解释性独白。对白声称的动机也要与实际行为对照。

**边界与反例（本产品推论）**：人物不必理性、讨喜或最终改变。假设一名长期隐瞒债务的人又撒了谎，这可能是性格在压力下的延续；不能因为他没吸取教训就扣分。动机可以暂不揭示，但后文应有支持当前解释的证据；没有证据时不要替作者补心理活动。
