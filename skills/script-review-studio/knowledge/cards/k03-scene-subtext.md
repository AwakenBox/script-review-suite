# K03 场景与潜台词：人物借谈话做什么

ID：K03。关联维度：V1-04、V1-05、V1-06、V1-09、V2-02。

**来源概括**：Sundance 对 Glen Mazzara 电视剧写作课的整理强调人物欲望，并举《盾牌》的谈话场景说明：表面讨论事件的同时，可以显露未说出口的欲望与关系；有价值的场景未必只负责铺设下一情节点。

**判断用法（本产品推论）**：把场景拆成“表面话题、各自想取得的结果、说话或动作所用的办法”。比较进场与离场时的信息、关系、处境或情绪。批评台词直白时，具体指出人物在什么处境下本可回避、试探或掩饰；不要只贴“缺少潜台词”的标签。

**边界与反例（本产品推论）**：紧急告警、真诚告白、笑话或风格化宣言可以直接说。假设人物终于承认多年不肯说出的事实，直白本身可能是场景的转变。日常闲谈也能建立亲密感；“没有争吵”或“没有新情节点”不能单独证明场景无用。

**来源**：[Glen Mazzara’s Six Rules for Writing a Compelling TV Episode](https://www.sundance.org/blogs/six-rules-for-writing-a-compelling-tv-episode/)，Write Money Scenes、Take a Character Pass。Sundance Collab team，2024-07-16；查阅：2026-09-11。该讲座是电视剧创作经验，不是所有叙事的强制规范。
