# K04 无对白与视觉叙事：信息能否被看见听见

ID：K04。关联维度：V1-06、V1-09、V1-10、V2-04、V3-03。

**来源概括**：Martin McDonagh 在 BFI 原访谈中谈到《七个神经病》的少对白回溯段落：对他而言，图像叙事需要额外思考画面、调性与分镜，并与摄影指导讨论，不能只沿用擅长的人物对白写法。

**判断用法（本产品推论）**：对每个关键心理或信息，找出原稿中的可见行动、物件变化、空间关系或声音线索，再说明观众可以据此理解到哪一步。例如“她不想让他离开”可以由挡住门口又让开的行动承载；这是假设示例，不能替用户原稿补写后算作已有证据。

**边界与反例（本产品推论）**：无对白不等于无声，也不自动更高级。人物说一句话就能准确完成的事，可以用对白。反例是满页镜头术语却没有明确行动关系，仍可能难以理解。评剧本只判断写出的构想，不能预先把未来表演、摄影和剪辑的效果算进去。

**来源**：[Seven Psychopaths: Martin McDonagh interview](https://www.bfi.org.uk/interviews/seven-psychopaths-martin-mcdonagh-interview)，关于 fragmented narrative 的问答。Sam Wigley 采访，2012-12-07；查阅：2026-09-11。创作者经验作参考，不作无对白优先规则。
