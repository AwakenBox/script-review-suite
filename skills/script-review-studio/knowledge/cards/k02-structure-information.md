# K02 结构与信息：看安排改变了什么

ID：K02。关联维度：V1-03、V1-07、V1-08、V2-04、V2-05、V2-06。

**来源概括**：Academy Nicholl 的故事评审问题兼顾叙事发展、读者旅程与情感连接，并明确把非线性故事是否成立纳入判断，没有将按时间顺序叙述设为前提。

**判断用法（本产品推论）**：分开记录“事件实际何时发生”和“读者何时得知”。每个关键揭示都问：此前让人期待什么，现在补足或推翻什么，后续注意力转向哪里。若一段只有补背景，尝试说明提前或延后会改变哪一种体验；说不出影响时，再检查它是否重复。

**边界与反例（本产品推论）**：提前给出结局可以把“会不会发生”转为“为何发生”，不等于失去悬念。开放结尾也可能完成情感回报。反过来，仅把事件打乱、最后补一段解释，不自动构成有效结构。先看原稿是否建立可追随的线索，不能按固定页码要求转折。

**来源**：[HOW TO APPLY — Nicholl Reader Judging Criteria](https://www.oscars.org/nicholl/about)，Story、Meaning and Magic 小节。页面未标该小节更新日期，含2024赛事资料；不作现行赛事规则。查阅：2026-09-11。时间双线和揭示检查是本产品的应用方法。
