# C03｜场面安静，观看也可以向前走

本产品原创教学材料。未经专家校准，不是真实影片或基准分；只比较证据是否充分。

关联：V1-06 场景组织；V1-08 节奏与篇幅配置；V2-05 持续吸引力；V4-03 持续观看动力。

**版本 A**

> 看门人坐在门岗，望着关上的厂门。钟走了一分钟。接着又一段：他仍坐着，厂门仍关着。文字只补充：“漫长，孤独。”

**版本 B**

> 看门人坐在门岗。钟走了一分钟，他习惯性伸手按开门钮，又缩回来。风把地上的停工通知翻过一角。他拎起包，到门边又折返，把桌上两只茶杯都洗了。

两段都慢，也没有争吵或反转。B 让我们逐步理解：他还保留上班的习惯，这里曾经不只他一个人。他没有离开这件事因此增加了分量。A 的第二段目前重复相同状态，仅靠说明文字，尚不足以解释延长的作用。

可以这样提意见：“这里不用加冲突，但第二次等待最好让我们多知道一点他为什么舍不得走。”

别要求每个静场都有新情节。时间的延续、重复和声音本身也可能构成体验，需要结合全篇与具体视听安排判断。V4 还必须固定平台、时长和受众；不能据此断言 B 一定更高完播，也不能把快剪当作通用答案。
