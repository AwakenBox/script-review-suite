# C02｜留白留下什么

本产品原创教学材料。未经专家校准，不是真实影片或基准分；只比较证据是否充分。

关联：V1-09 对白与信息传递；V2-04 结构与信息组织；V3-03 视听构想。

**版本 A**

> 她摆好两套餐具，坐到天黑。门外响起脚步，她拿走一双筷子。门没开。她把那双筷子放回抽屉最深处。

**版本 B**

> 她坐到天黑，忽然打开抽屉，把一双筷子藏起来。门外响起脚步。她笑了。镜头停住。说明文字：“她终于原谅了母亲。”

A 没有说明等的是谁，却给出可见的期待与落空：两套餐具、脚步、撤走筷子。观众可以理解她的处境，也可以对关系保留不同猜想。B 的动作同样能被拍到，但“原谅母亲”只有说明文字支撑，笑也可能被读成别的情绪。

若作者想让观众明确理解“原谅”，可以问前文是否建立了母亲与筷子的联系；不必立刻加解释台词。若目的只是制造不确定感，B 的暧昧未必是问题。

别因看不懂某个象征就判它无效，也别因为没有对白就夸它高级。要核对作品究竟希望观众知道什么，以及画面和声音是否提供了足够线索。这两段只支持局部判断，不能据此评价全篇艺术水平。
