# C01｜说出理由，还要看选择

本产品原创教学材料。未经专家校准，不是真实影片或基准分；只比较证据是否充分。

关联：V1-04 人物动机与行动；V2-02 人物与关系成立度。

**版本 A**

> 林悦收好去外地的车票。父亲来电，她挂断。下一场，她退票回家：“我想通了，家人最重要。”

**版本 B**

> 林悦把车票夹进辞职信。父亲留言：“你的房间收拾好了。”她删掉留言。候车时，弟弟发来照片：父亲坐在楼梯上，腿缠绷带。她回拨：“你先别扶他，我打急救电话。”检票广播响起，她仍在向接线员报地址。

能核对的差别是：A 有改变决定的宣言，没有交代什么促成改变；B 增加新处境，也让人物为照顾父亲承担错过车次的代价。B 对“她此刻为何留下”提供了更充分的证据，却还不能证明父女已经和解。

评稿时可以直接说：“退票来得突然。前面补一个让她改变决定的新情况，会比结尾解释更管用。”

别把它用成“所有动机都要交代清楚”。隐瞒动机可以形成悬念；如果前文早已充分建立牵挂，A 也可能只需一个停顿。动作不是天然优于台词，关键是选择能否被理解。
