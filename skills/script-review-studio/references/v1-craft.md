# V1：剧作工艺与完成度

规则版本：0.1.0。12 项，各 10 分；`score_10` 为 0—10 整数，呈现分数与其相同，完整评分满分 120。

## 定位与材料

回答：作为影视剧本，写作各环节是否扎实，文本是否足以支持理解、表演和制作协作？

优先使用完整剧本，或已充分呈现场景、行动、对白或其他信息传递方式的文本。梗概通常不足以判断场景组织、节奏和交付清晰度；不能据此替未写出的场景评分。非标准排版不自动扣分，实际歧义才影响交付清晰度。

先按每项证据判断 `score_10`；下表的 6、8 分是功能锚点，允许使用其间整数。缺少判断材料标暂不可评，不记 0 分。总分、缺项处理及“全面优秀”资格按主文件统一规则执行。

## 分项锚点

| ID | 维度 | 6/10：基本有效，存在明确不足 | 8/10：稳定有力，关键效果有证据 |
|---|---|---|---|
| V1-01 | 核心前提与设定 | 核心情境清楚，规则大体成立，但设定对篇幅或后续发展的支撑有限 | 核心情境与规则明确、自洽，设定持续产生有效行动或关系问题，足以支撑预定篇幅 |
| V1-02 | 叙事逻辑 | 主要事件可以理解，但关键连接存在便利巧合或未说明的条件 | 事件发生的条件及其后果可追溯，关键发展不靠无依据的巧合、规则变化或人物失智 |
| V1-03 | 整体结构 | 开展和收束基本成立，但重要段落位置、铺垫或回应存在失衡 | 段落排列服务于作品体验，铺垫、发展与收束互相支持，关键安排难以随意替换 |
| V1-04 | 人物动机与行动 | 主要行动符合人物，但一次重要选择或转变缺少支撑 | 关键选择来自具体欲望、处境和性格，行动的代价与后果进一步揭示人物 |
| V1-05 | 人物关系与发展 | 关系可辨认，但推进主要靠说明，或变化缺少过程 | 关系通过行动与互动形成层次；变化或坚持均有过程、压力和代价 |
| V1-06 | 场景组织 | 多数场景有作用，但局部重复信息、静置人物或缺少明确推进 | 场景承担清楚功能，场内行动使信息、关系、处境或情绪发生有效推进 |
| V1-07 | 张力与期待 | 能建立关注点，但较长段落没有维持或更新期待 | 通过冲突、悬念、好奇或情感牵引持续组织关注，期待的建立、延宕与回应有效 |
| V1-08 | 节奏与篇幅配置 | 总体可读，但重要内容过短、次要内容过长或转换突兀 | 篇幅与重要性相称，快慢、停顿和转换服务于体验，静场也有必要的持续时间 |
| V1-09 | 对白与信息传递 | 关键信息能被理解，但局部生硬说明、重复或人物声音趋同 | 信息通过对白、动作、环境或沉默自然准确地传达，表达方式符合人物与场景 |
| V1-10 | 视听可呈现性 | 多数内容可表演呈现，但关键心理或意义仍依赖抽象解释 | 关键内容落实为可见、可听、可表演的事件与细节，表达不依赖观众读到说明文字 |
| V1-11 | 情感与主题兑现 | 建立的情感或表达意图可辨认，但关键回应偏弱或只靠台词总结 | 情感期待与表达意图通过事件和选择获得充分支撑，收束符合此前积累 |
| V1-12 | 文本交付清晰度 | 基本可理解，但局部人物指代、时空转换或动作关系需要猜测 | 场景、人物、时空和动作关系清楚，必要信息充分，阅读和制作协作中的关键歧义少 |

## 容易误判的边界

- 逻辑问“为何发生”，结构问“如何排列”，节奏问“分配多少篇幅”，张力问“观众等待什么”。同一问题影响多项时分别说明实际后果，不能复制扣分理由。
- 不要求三幕式、强冲突、反转或角色转变。判断作品所选组织方式是否产生预期效果。
- 无对白时，V1-09 评价非语言信息传递；缓慢叙事的 V1-08 评价时长配置，不以速度作为分数。
- V1-11 不要求宏大主题或社会议题。私人经验、幽默、感官或情绪表达也可充分兑现。
- V1-10 评价能否呈现；视听表达是否独特、形式是否有艺术作用，交给 V3。镜头术语的数量不作为加分依据。
- 制作成本、演员资源、市场规模不是本模式扣分项；有明确条件时另作项目适配说明。
