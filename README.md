# 剧本四镜 · Script Review Suite

**和你一起看剧本，说清哪里成立、哪里卡住、下一稿先改什么。**

两款面向 AI 助手的中文 Skill，分别服务创作者与项目团队。默认用几段自然对话讨论具体情节；需要时再展开评分、版本对比或评审材料。

## 聊起来是什么样

下面是一个原创教学情境：女儿藏着车票，父亲把捡到的求职信原样递回。下一场，女儿主动拿出车票。

> **你：** 这段要不要加一句“我支持你”？
>
> **助手：** 我会先留住父亲没有拆信这个动作。他把选择交还给女儿，已经能让人感觉到他的态度。更值得补清的是：女儿有没有发现信没被拆开？一个短反应，就可能让她后来主动拿出票更有来处。加上“我支持你”，态度会更明确，但那点犹豫和默许也会变少。

## 选哪个 Skill

| Skill | 适合谁 | 可以直接这样问 |
|---|---|---|
| [`script-review`](skills/script-review/SKILL.md) | 编剧、导演、个人创作者 | “这场人物转变可信吗？”“只看故事，下一稿先改哪里？” |
| [`script-review-studio`](skills/script-review-studio/SKILL.md) | 工作室、制片人、内容团队 | “这三份稿先聊哪份？”“按我们的拍摄条件，哪里需要调整？” |

两版共用评分规则。团队版把作品质量与项目适配分别判断：超出预算或场地条件，不会直接变成低质量；未知条件也不会被当成不合格。

## 四个视角，按需使用

- **V1 工业**：剧作工艺与完成度，12 项 × 10 分。
- **V2 故事**：故事是否成立、吸引人、打动人，6 项 × 20 分，不要求剧本格式。
- **V3 艺术**：作者表达、视听构想与艺术潜力，6 项 × 20 分。
- **V4 传播**：给定平台、时长与受众下的传播潜力，6 项 × 20 分。

每套满分 120，分别呈现。平常评价不自动打分；你问“多少分”时才核算，明确要分项时再展开。材料不足会说明缺口，不补写情节凑分。V1 的“全面优秀”同时检查总分与单项底线。

## 判断从哪里来

内置 **8 张有来源的知识卡、4 张原创对照案例**，覆盖人物动机、结构、潜台词、无对白、慢叙事、作者表达、影展差异与受众满足。通过本地中文关键词、标签和别名检索，按具体问题读取相关知识与反例。

原稿是判断依据，知识用于检查解释是否适用。检索不能替代读完整稿；慢叙事、开放结局或没有对白，都不会单独成为扣分理由。知识来源和原创教学案例也有明确区分。

## 安装与使用

1. 下载并解压 [0.2.0 组合安装包](packages/script-review-suite-0.2.0.zip)。
2. 将需要的 `script-review`、`script-review-studio` 文件夹复制到 `~/.codex/skills/`。如果设置了 `CODEX_HOME`，则复制到其下的 `skills/`。
3. 在 Codex 新任务中附上剧本，输入：

```text
$script-review 看看这个故事，直接聊最影响它的一两处。
```

```text
$script-review-studio 比较这两份稿。我们的条件是两位演员、单一室内场景。
```

其他支持这类 Skill 的宿主，请按其技能目录安装。这里提供的是 Skill 文件，运行需要宿主中的 AI 助手。检索与计分脚本使用 Python 3.10+ 和标准库，无需另配 API Key；宿主的模型配置与费用另计。没有 Python 时也可以直接读取知识索引，评分按协议人工核算并说明。

## 维护

在仓库根目录运行：

```sh
python -m unittest discover -s skills/script-review/scripts -p 'test_*.py'
python scripts/build_package.py
```

打包脚本从 `skills/` 构建安装包并写入 `packages/`。修改共用规则或知识时，需要同步两个 Skill。

当前产品版本 **0.2.0**，评分规则与知识库版本均为 **0.1.0**。规则仍在试行，教学案例不代表真实专家校准；分数不预测入围、播放量或商业回报。请勿把用户原稿、评审数据或团队私有资料提交到公开仓库。
